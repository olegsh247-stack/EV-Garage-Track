# EV-Garage-Track

Каталог **коммерческого электротранспорта из Китая** для российского бизнеса:
электрические грузовики, закрытые фургоны и рефрижераторы грузоподъёмностью
**1.0–3.5 тонны**. Сайт на Next.js (App Router) + TypeScript + Tailwind CSS.

Проект адаптирован из [EV-GARAGE](https://github.com/olegsh247-stack/EV-GARAGE)
(каталог легковых электромобилей) под B2B-нишу коммерческого электротранспорта.

## Что внутри

- **Каталог** марок и моделей (бренд → модель → версия).
- **Карточка модели** с характеристиками по разделам: грузовые параметры,
  кузов, батарея и запас хода, двигатель, зарядка, габариты и шасси,
  эксплуатация, гарантия и (для рефрижераторов) холодильная установка.
- **Рейтинги** на главной: топ по запасу хода, по грузоподъёмности, по объёму
  кузова и самые доступные модели.
- **Сравнение** до 4 моделей по всем характеристикам.
- **Страница «Таможня»** (`/customs`) — логика таможенного оформления
  электрогрузовиков: ТН ВЭД 8704, пошлина, НДС 22% (с 2026 г.),
  утилизационный сбор, таможенный сбор, сертификация ОТТС/СБКТС/ЭПТС.

## Данные

Все данные каталога хранятся локально в TypeScript-файле и строго типизированы:

- `src/data/vehicles.ts` — бренды, модели, версии (тип `Trim`) и вспомогательные
  функции (`topModelsBy`, `specSections`, `similarTrims` и др.).
- `src/data/contact.ts` — контакты.
- `public/images/trucks/` — изображения-плейсхолдеры моделей (SVG).

Никакого парсинга в рантайме нет — контент редактируется через файлы данных.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Сборка

```bash
npm run build
npm run start
```

## Деплой

Проект рассчитан на деплой на [Vercel](https://vercel.com) как отдельный
проект. Для загрузки реальных фото моделей используется Vercel Blob
(переменная `BLOB_READ_WRITE_TOKEN`); без токена показываются плейсхолдеры.

> Характеристики и цены в каталоге — ориентировочные и требуют подтверждения по
> официальным спецификациям производителей перед публикацией.
